## A / 两个相邻源整字如何合成8字节

`WORDCOPY_FWD_DEST_ALIGNED`第三参数`len`的单位是**8字节op_t个数**。它先计算`sh_1=8*(srcp % OPSIZ)`与`sh_2=8*OPSIZ-sh_1`，把源整数游标向下取到8字节边界。所选小端宏表达式为`MERGE(w0,w1)=(w0 >> sh_1) | (w1 << sh_2)`，按64位无符号字截断。单字copy且余数1时预读`a2=srcp[0]`、`a3=srcp[1]`两个完整源字，再经case1判断直接`goto do0`，最后一次`do0`写`MERGE(a2,a3)`到目的D+128；整数指针调整本身不构成读取或写入。
